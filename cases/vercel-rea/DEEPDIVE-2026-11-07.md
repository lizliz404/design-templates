> TEARDOWN.md 只测了间距；本文补 Liz 六轴里它没讲的部分：A header 滚动 / B 菜单开合 / C 信息密度 / D 图文关系 / E 滚动叙事 / F footer。

## 0. 一页结论

- **A**：`sticky top-0` 64px 常驻，永不隐藏/收缩；`scrollY>0`（内联脚本 rAF 轮询，**任何滚动立即生效**）→ `data-[scrolled]` → 透明底换 `bg-background-200` + `0 1px 0 var(--ds-gray-alpha-400)` 发丝线。切换无 transition = 瞬时。
- **B**：桌面 mega-menu **没有任何开合动画** —— `invisible→data-[open]:visible` 瞬时切换 + chevron `rotate-180` + `transition-none`；只有 backdrop 遮罩（`bg-background-200/50`）做 opacity 淡入。移动菜单 = `opacity-0→100` 淡入的全屏 dialog + 原生 `<details>` 手风琴。logo 弹层用了最新 `popover="manual"` + `open:duration-100` + `starting:open:opacity-0`（@starting-style 入场）。全站动效语言 = **100–150ms fade/color，宁瞬不拖**。
- **C**：营销面稀疏——h1 两三个词（"Agentic Infrastructure"）、section 标 `heading-32→48→56`、右栏一句客户数据（heading-24）；pricing 面密度升档但仍短行（套餐卡 6–8 条 2–5 词 bullet）。刻度 = Geist 4px 基（TEARDOWN 已测）。
- **D**：图 = **产品 UI 截图**，无框无边——aspect 容器裁切（移动 4/3，桌面 12/6=2:1）+ **底缘 `h-40 linear-to-t from-background-200` 渐变把截图溶进页面底色** + 深色模式下 `blur-[120px]` 光晕垫底；所有截图 light/dark 双版本按主题切换。
- **E**：几乎无滚动叙事——DOM 未检出 IntersectionObserver/in-view reveal 类；滚动感只靠 hero 的 canvas（triangle-LED 着色器 + `hero-zoom-freeze` 变量）与移动端 logo marquee（50s）。
- **F**：footer = 目录网格（"Vercel Directory"，4→6→8→12 列，组占 2 列，`text-label-14` 眉 + `leading-5` 链接 + `New` oklch 药丸）+ 底栏功能件（左：vercel-status 实时状态药丸；右：system/light/dark 主题切换 + "View as AI agent"钮）。**注意力在"目录完备性 + 状态/主题功能"，没有任何巨字。**

## A · 顶部菜单滚动行为

**结论：常驻 sticky 64px，滚动只触发"透明→实底+发丝线"瞬时换肤，阈值 = scrollY>0。不消失、不收缩、不变形。**

DOM 实证（`home-1440-dom.html`，docs 页同组件）：

```html
<header id="marketing-header" data-navigation-header
 class="peer sticky top-0 z-(--header-zindex) h-(--header-height) w-full bg-transparent
        data-[scrolled]:bg-background-200
        data-[scrolled]:shadow-[0_1px_0_0_var(--ds-gray-alpha-400)]
        data-[nav-open]:!shadow-none data-[nav-open]:bg-background-200
        data-[mobile-open]:!bg-background-100 data-[mobile-open]:!shadow-none">
```

内联脚本原文（DOM 内 `<script>`，首屏无 JS 依赖即生效）：

```js
(function g(){function a(){
  let a=document.getElementById("marketing-header");
  a&&(window.scrollY>0 ? a.dataset.scrolled="true" : delete a.dataset.scrolled)}
  a(); requestAnimationFrame(a);
  window.addEventListener("scroll",function b(){a();
    window.removeEventListener("scroll",b)},{passive:!0,once:!0})})()
```

- 阈值 **scrollY>0 = 滚动 1px 即换肤**，无过渡类 → 瞬时硬切（与 saronic `onLeave` 硬切同思路，但阈值极端小）。
- `data-[scrolled]` 只换 `background` + `box-shadow` 发丝线；`data-[nav-open]`（mega 菜单开）强制 `bg-background-200` 且无阴影；`data-[mobile-open]` 用 `bg-background-100` —— **三个状态三档底色**，菜单开着时 header 与面板同色无缝。
- 脚本用 rAF 持续轮询 + `once:true` 的 scroll listener 双保险 —— 滚动开始后每帧校对，没有监听漏网窗口期。
- `h-(--header-height)` 变量化 64px；docs 页复用同一 header 组件（同样 `data-scrolled` 机制），是"一把尺 per surface"但**导航组件跨 surface 复用**。

## B · 菜单开合动画

**结论：桌面 = 零动画瞬时切换（只 backdrop 淡出）；移动 = opacity 淡入 dialog + 原生 details 手风琴；图标切换 = 两个 svg `hidden/block` 硬换不做 morph。全站动效预算 100–150ms。**

### B1. 桌面 mega-menu（Products/Resources 下拉）

```html
<button data-nav-id="products" aria-expanded="false" aria-controls="nav-panel-products">
  Products <span class="transition-none data-[open]:rotate-180"><svg chevron/></span>
</button>
<div id="nav-panel-products" aria-hidden="true" inert
  class="invisible data-[open]:visible fixed inset-x-0 top-(--header-height)
         bg-background-200 shadow-[0_1px_0_0_var(--ds-gray-alpha-300)]
         before:absolute before:inset-x-0 before:-top-3 before:h-3   /* hover 桥，防 gap 丢焦 */">
```

- 开/关 = `invisible→visible` + `inert` 属性切换，**无 transition/keyframes** —— 面板瞬间出现；chevron `data-[open]:rotate-180` 配 `transition-none` 也是瞬时翻转。
- 唯一动效在 backdrop：`fixed inset-x-0 bottom-0 top-(--header-height) bg-background-200/50 opacity-0 will-change-[opacity] peer-data-[nav-open]:opacity-100` —— 面板开时全页下半部蒙 50% 底色的遮罩（opacity 过渡）。
- `before:-top-3 h-3` 透明桥接带补 trigger 与面板之间的 12px 空隙 —— 防 pointer 过隙关菜单的低成本招。
- 面板内容：1400 轨容器内 `pt-1 pb-6`，`min-w-[250px]` 分组（"Agent Stack" label-14）+ `text-label-20` 大链接列。

### B2. logo 品牌弹层（彩蛋件）

```html
<div id="logo-branding-menu" popover="manual" role="menu"
 class="w-[325px] rounded-xl border border-gray-alpha-400 bg-background-100 p-1.5
        opacity-0 open:opacity-100 starting:open:opacity-0 transition-opacity open:duration-100">
```

- 原生 Popover API + `starting:open:`（@starting-style）做 100ms opacity 入场 —— 2025+ 浏览器特性实战样本。
- 内容 = "Copy Wordmark"/品牌资产按钮网格（点 logo 不是回首页，是开品牌菜单）。

### B3. 移动菜单

- 按钮 `aria-label="Open menu"` `min-h-11 min-w-11`（44px），`translate-x-2.5` 视觉对齐补偿；图标 = 汉堡/X 两个 svg `hidden` ↔ `group-data-[open]:block` 硬换。
- 面板 `role="dialog" aria-modal` `invisible opacity-0` → `data-[open]:!visible !opacity-100 !block`，`fixed inset-0 top-(--header-height) overflow-y-auto` 滚动条隐藏。
- 内部 = 原生 `<details name="mobile-nav">` 手风琴（同 name 互斥展开），行高 `min-h-11`，`text-[22px]`。
- 断点 ≤880px 换移动形态（`max-[880px]:hidden` 桌面 nav/面板）。

### B4. 全站时长纪律（DOM 类名普查）

`duration-[time:150ms]` ×12（按钮/触发器 `transition-[border-color,background,color,transform,box-shadow] ease-in-out`）、`open:duration-100`（popover）、`duration-100`（footer 链 hover）、`transition-colors` ×196、`transition-opacity` ×17、`motion-reduce:transition-none` 随处可见。**微交互 100–150ms，hero 幕布 700–1200ms（canvas fade）**，中间档基本没有。

## C · 信息密度

**结论：营销面"一屏一事"——h1 两三个词、section 一大标 + 一句客户数据 + 一排特性列；pricing 密度升档但仍是短行。**

实测（`home-1440-dom.html`/`pricing-1440-dom.html`）：

| 位置 | 内容 | 量 |
|---|---|---|
| hero | `Agentic Infrastructure`（h1，heading-48→64，font-normal）+ scramble 轮播小字 + 2 CTA | 2 词 |
| 产品 section | h2 `heading-32→48→56` col-span-8（"Build agents on infrastructure that thinks like them"，7 词）+ 巨截图 + 右栏客户数据句（heading-24，`text-gray-900` 内嵌 `gray-1000` 客户名）+ `Features` 列（label-14，4–5 项） | 标 ≤8 词 / 数据句 ≤12 词 |
| 客户 logo 墙 | Meta/DoorDash/OpenAI/SpaceXAI/The Weather Company/Polymarket svg | 6 logo |
| `Recently shipped` | `mt-20` + changelog 卡网格（`aspect-4/5→1.2`，blueprint 芯片图） | 卡 = 图+短题 |
| pricing | h1 `Scale your app, control your costs`（6 词）+ 套餐卡（plan 名 + `$0/mo` + 一句定位 + 6–8 条 2–5 词 bullet + CTA） | 卡 ≈40 词 |

- 字阶（DOM class）：`text-heading-20/24/32/48/56/64`、`text-copy-14/16`、`text-label-14/20`、`text-[12px]` mono；正文灰阶双档 `gray-900`（弱）/`gray-1000`（主）同句混排 —— **一句话里两档灰做强调，不靠粗体**（见客户数据句 `<span class="text-gray-1000">` 内嵌）。
- 行宽：h2 `max-w-[18ch]`（`text-balance`）、hero 副文 `max-w-sm`。
- 纵向：hero `min-h:min(100svh−64,1100px)`（836px@900 视口）；区块 `mt-40→mt-52` = **160→208px**；`Recently shipped` 组内 `mt-20`（80px）。

## D · 图片处理

**结论：全部是产品 UI 截图（webp，light/dark 双版），容器靠 aspect 裁切不加框，底缘渐变溶进页面底色，暗色下垫光晕——"框"被擦除而不是被画上。**

### D1. 产品 section 图（`home-1440-dom.html`）

```html
<div class="relative isolate overflow-hidden bg-transparent aspect-4/3 @sm:aspect-12/6">
  <img class="[.light-theme_&]:!hidden …" /><img class="[.dark-theme_&]:!hidden …" />  <!-- 主题双版 -->
  <div class="absolute inset-x-0 bottom-0 h-40 bg-linear-to-t from-background-200 to-transparent"/>
</div>
<div aria-hidden class="absolute inset-0 bg-gray-1000 h-40 rounded-full blur-[120px] dark:opacity-15 opacity-0"/>
```

- 容器只规定 `aspect` + `overflow-hidden`，图 `h-auto w-full` 自然铺满；**底缘 160px 渐变把截图"融化"成 `background-200`** —— 图与页面无接缝，所以读不到框。
- 每图两个 `<img>`（light-theme/dark-theme 互斥 `!hidden`）—— **截图跟主题换肤**，深色站里不放一张发白的界面图。
- `blur-[120px]` 圆角光晕（仅 dark 15%）垫在图后 = 软投影替代边框。
- `pointer-events-none select-none` —— 图纯展示不可交互。

### D2. hero canvas（`data-hero-*`）

- `data-triangle-led-4-hero-canvas`（1080×720 canvas，`duration-1200` ease-linear 淡入）+ 静态兜底：`mix-blend-mode:luminosity` 截图 + `fallback-dark-noise.webp` 70px 平铺 `mix-blend:multiply;opacity:.42` 噪点。
- 变量 `--hero-canvas-max:720px; --hero-zoom-freeze-h:560px; --hero-shader-y-offset:20px` —— 【推断】shader 图按滚动/视口做 zoom 至 560px 冻结（`zoom-freeze` 命名），canvas 方案 CFE 不学，但**静态兜底（luminosity 混合 + 噪点 multiply）**可低成本仿"渲染图质感"。
- `data-hero-drop-active/staging`：把文件拖进页面会出 "Drop to deploy"/"Loading"（300ms fade）——彩蛋级交互。

### D3. 其他图

- avatar `size-8 rounded-full` + `shadow-[inset_0_0_0_1px]` 内描边；
- changelog 卡 = "blueprint 芯片图"（mono 标签块摆在 blue-600/700 渐变上，`aspect-4/5→1.2`）—— **用产品语言画插图，不用摄影**。

## E · 滚动叙事

**结论：Vercel 营销面基本是"静态版式"——DOM 无 IntersectionObserver/in-view reveal 类、无 scrollspy；滚动驱动的只有 header 换肤和 hero canvas（推断）。触发叙事的是时间和 hover，不是滚动。**

- `grep` 全 DOM：`IntersectionObserver`/inview/reveal 类 = 0 命中；`addEventListener("scroll"` 仅 header 一处。
- 动的时间件：hero `data-scrambling` 文字乱序轮播（"For coding agents/To ship apps and agents…"，300ms fade 换句）、移动 logo marquee（`--marquee-speed:50s`，`motion-reduce` 降级为手滑）、`duration-1200` canvas 淡入。
- docs 面有章节机制但属于文档系统：侧栏 `lg:sticky top-(--header-height) h-[calc(100svh-var(--header-height))]` 粘性目录、"Copy link to section" 锚链、右栏 `transition-[width] duration-250` 可收起的 AI 面板。
- 对 Liz 的问题"hover 触发还是滚动触发"——**Vercel 答案：都不，它用时间轮播（marquee/scramble）+ hover 揭示（nav/hairline 变色）**，滚动只换 header 皮肤。

## F · Footer 注意力分配

**结论：footer 是"站点目录 + 功能底栏"——注意力给"链接完备性"（10 组 × 6-8 链）与"状态功能"（status/主题/AI 视图），没有巨字、没有 CTA、甚至没有 © 行。**

结构（`home-1440-dom.html`，`py-10 text-[14px]`，1400 轨）：

```
nav[aria-label="Vercel Directory"]: grid 4→6→8→12 列，每组 col-span-2
  ├ h2 text-label-14 font-medium gray-1000（Agent Stack/Core Platform/Security/Tools/
  │  Frameworks/SDKs/Build/Learn/Explore/Company/Legal）
  └ li text-gray-900 py-0.5 leading-5，hover→gray-1000，duration-100；
    "New" 药丸：11px/20px tracking-.2px，oklch(from var(--ds-gray-200)…) 派生底
底栏（flex）:
  ├ 左：→vercel-status.com 状态药丸（status-dot + mono uppercase 12px "Loading status…"）
  └ 右：theme radio fieldset（system/light/dark，peer-checked 药丸高亮）+ "View as AI agent" 钮
```

- 链接密度极高（10 组 ≈60+ 链）但**全部同一档**（label-14 眉 + copy-14 链）——靠"齐整"而非"层级"组织注意力；与 saronic（巨字链接做主角）是两个极端。
- 功能件做注意力锚点：实时 status（外链监控页）+ 主题切换 + "View as AI agent"（AI 可读版入口，2026 才有的件）—— footer 右下 = 功能角。
- docs 页复用同 footer（marketing 轨），在 docs 全宽布局里形成第二把尺（TEARDOWN 已测双轨）。

## CFE 可抄清单（次级参考，saronic 为主）

- **A**：最简方案直接抄——`scrollY>0` 一行 JS 换 `data-scrolled` → 实底 + `0 1px 0 alpha` 发丝线，瞬时即可；比 saronic 的 ScrollTrigger 轻一个量级。
- **B**：菜单开合 CFE 应该学 vercel 的**克制**（瞬时/≤150ms）而不是 saronic 的 500ms 抽屉——B2B 询盘站菜单是工具不是秀。可偷：`before:-top-3 h-3` hover 桥、`popover="manual"` + `starting:open:opacity-0` 的 100ms 弹层、移动菜单同 name `<details>` 互斥手风琴。
- **C**：两档灰同句混排（gray-900 句子里嵌 gray-1000 词）替代粗体强调；"New" 药丸用 `oklch(from var(--ds-gray-200) …)` 从既有 token 派生不造新色；功能列表 `Features` 眉（弱灰）+ items（主灰）的结构可直接搬进 CFE 产品卡。
- **D**：核心招——**截图/渲染图底缘 `h-40 linear-to-t from-页面底色` 溶解**，比任何边框都更像"图和文共舞"；light/dark 双版图机制在 CFE 不需要（单主题），但"产品实拍图按深浅底各备一版 scrim"思路可用。
- **E**：别学它"什么都没有"——CFE 至少保留 IO reveal；可学 `motion-reduce` 全面降级（marquee→手滑、transition→none）的兜底习惯。
- **F**：CFE footer 取 vercel 的"功能件"而非它的密度——目录列收敛到 CFE 的 4–5 组；右下功能角可放"ISO/船级社资质标 + 邮箱/微信"替代它的 status/theme/agent。
