## 0. 一页结论

- **A**：header = `position:sticky; top:0; height:64px`，**常驻、不消失、不收缩**。滚动唯一改变的是"主题"：首页 `data-animated=true` 时透明底 → 滚过 100vh 由 ScrollTrigger `onLeave` 硬切成**浅底深字**（sunlight100 底/midnight300 字），滚回 `onEnterBack` 清掉；非首页 `data-animated=false`，按页注入 `--fg-color/--border-color/--hover-color` 主题变量。JS 里有完整的"下滑隐藏/上滑显示"方向检测（66ms 去抖、路由变更后 1s 才启用），输出到 `data-hidden` 属性——但 CSS 没有消费方，**当前构建里是死代码**。
- **B**：菜单是原生 `<dialog>` 右侧抽屉：进 `.5s cubic-bezier(.25,.25,0,1)`（签名缓动）+ backdrop `.5s linear` 淡入（`rgba(0,0,0,.333)`）；出 `.25s cubic-bezier(.5,0,.75,1)` + backdrop `.25s` —— **关比开快一倍**。图标无 morph：header 的"Menu+两线"按钮永远不变，X 是抽屉内独立关闭钮。菜单卡 hover 揭示/隐藏也是非对称（揭 `.125s ease-out`，隐 `.25s ease-in`）。
- **C**：典型 section = mono eyebrow（2–3 词）+ heading-large 标题（4–6 词）+ 一句 body（14–18 词）+ 至多一个 CTA。PageIntro 行宽 40ch、NewsSection 56ch、卡描述 45ch、footer 推销句 18ch。垂直节奏 `spacing-section` 80→120→160、`page-margin` 16→24→32→40。
- **D**：图没有"框"靠三招 —— ①图永远 `object-fit` 铺满容器，容器即图（MediaCard = 8px 圆角裁切 + 底渐变 + 左下角叠字）；②scrim 把图边缘溶进页面底色（hero 用 5-stop 渐落到 `#162029`）；③`split-image-bleed` 让图贴视口边、文字留在 margin 内，桌面端图反而 `object-fit:contain` 底对齐飘在 section 底上。从不出现"卡片套图再套说明"的俄式套娃。
- **E**：**滚动触发，不是 hover 触发**。reveals 全走 IntersectionObserver + `data-shown`（clip-path wipe 1s、translateY(10vh)+fade 1s 延迟 1s）；GSAP scrub 只在首页两处（视频底 opacity→.2、header 主题渐变 0→100vh）；锚点导航只有 careers 页 AnchorBar（data-sticky）；portalpha 用 sticky aside + 72→128px 18% 透明巨号章节码做章节感。
- **F**：footer 注意力在**导航链接本身**——链接直接用 `type--heading-large`（32→64px 巨号字），是全 footer 最大文字；1px cell 网格分出 3 列（logo/Join Our Mission/Address | Technology | Company），右下角是实时坐标 MouseTracker，唯一 sonar 实色按钮是招聘外链。

## A · 顶部菜单滚动行为

**结论：常驻 sticky 64px，不消失不收缩；滚动只做"主题切换"——首页透明→100vh 处翻成浅底，其他页按页注入主题变量。另有一套没被 CSS 消费的"下滑隐藏"死接线。**

### A1. 基态结构（`css/3dcc14c5e1ce1ff3.css`）

```css
.SiteHeader{--fg-color:var(--color-midnight300);
  --border-color:var(--color-midnight300-10);
  --hover-color:var(--color-midnight300-3);
  --height:64px; display:grid; grid-template-columns:1fr 1fr;
  height:64px; background:var(--body-bg);
  border-bottom:1px solid var(--border-color);
  position:sticky; z-index:2000; top:0;
  transform:translateY(-100%)              /* CSS 默认藏起来，靠 JS/GSAP 放下来 */
}
.SiteHeader[data-animated=true]{background:transparent; --border-color:transparent}
@media(min-width:960px){.SiteHeader[data-animated=true] .HomeLink{visibility:hidden} /* 首页顶部 logo 让位给满屏 SARONIC 巨标 */
```

- `--fg-color/--border-color/--hover-color` 由**每页内联 `<style>` 注入**（vessels 深底页 = `--fg-color:sunlight100`，`evidence/vessels-1440-dom.html` 可见 `<style>` 块）；同一份 header 组件在深/浅页自动换色。
- 左格 logo（`border-inline-end:1px` 分隔，svg 宽 140px），右格 `CAREERS | MENU`（`type--caption-small` mono；JobsLink 与 `|` 分隔符 ≤639 `display:none`）。

### A2. 入场编排（`layout-*.js` AnnouncementBar 组件 effect）

```js
document.documentElement.style.setProperty("--announcement-bar-height","0px");
let e = document.querySelector("[data-site-header]");
let t = gsap.timeline();
t.fromTo(announcementBar, {y:"-100%",opacity:0},
  {y:"0%",opacity:1,duration:.6,ease:"power2.out",
   onUpdate(){ setProperty("--announcement-bar-height", h*progress+"px") }});
e && t.fromTo(e, {y:"-100%"}, {y:"0%",duration:.6,ease:"power2.out"}, 0);  // 同刻并行
```

- 公告条存在于**每个页面**（home/vessels/mission/portalpha DOM 均有 `data-announcement-bar`）。入场时公告条与 header 一起从 -100% 滑下 `.6s power2.out`；`--announcement-bar-height` 同步 0→64px，首页巨标 `LogoContainer` 的 `top:calc(var(--announcement-bar-height) + spacing-05)` 跟着被推下 —— 三个元素一支编舞。
- 无公告条时 `gsap.set(header,{transform:"none"})` 直接落地。
- 证据佐证：`portalpha-1440-dom.html` 的 header `transform:translate3d(0,-9.3165%,0)` = 捕获发生在入场 tween 约 70% 进度处（power2.out 残量 ≈9%），不是滚动联动。

### A3. 滚动时的主题切换（`layout-*.js` SiteHeader，`data-animated=Z`）

```js
gsap.timeline({scrollTrigger:{scrub:true, invalidateOnRefresh:true,
  start:0, end:()=>document.documentElement.clientHeight,   // 0 → 100vh
  onLeave(){ header.style.background="var(--color-sunlight100)";
            header.style.color="var(--color-midnight300)";
            --border-color:midnight300-10; --hover-color:midnight300-3 }, // 翻成"浅底深字"
  onEnterBack(){ /* 清空 inline，回到透明 */ }})
  .fromTo(header,{"--border-color":"rgba(242,246,250,0)"},
                 {"--border-color":"rgba(242,246,250,0.2)"},0)  // 底边随滚动渐进
  .to(".HomeLink",{autoAlpha:1},0)                               // 小 logo 0→1 随滚动淡入
```

- `data-animated` 只在首页为 `true`（vessels/mission/careers/contact/portalpha DOM 全部 `data-animated="false"`）。
- 首页行为链：顶部透明 + 无小 logo（巨标在 hero）→ 0–100vh 滚动中底边透明度 0→.2、小 logo 淡入 → **滚过整整一屏后 onLeave 硬切浅底深字**，回滚进入 100vh 内 onEnterBack 还原。即"header 只在内容区才出现底色"，临界点 = 1 viewport，不是像素阈值。
- 非首页：无 scrub，`--fg-color` 主题变量在挂载即生效，滚动只留 `border-bottom:1px` 作分隔。

### A4. "下滑隐藏"死接线（勘误项）

```js
[B,N]=useState(false);[R,A]=useState(false);            // R → data-hidden
useEffect(()=>{N(false);setTimeout(()=>N(true),1000)},[F]);            // 路由变更后 1s 才武装
useEffect(()=>{B ? (C==="DOWN" ? A(true) : C==="UP" && A(false)) : A(false)},[B,C]);
// scrollDirection hook：scrollY 增量方向，66ms debounce，停顿时归 null
<header data-hidden={R} …>
```

- 机制完整：武装延迟 1s + 方向检测 66ms 去抖 + DOWN→hidden/UP→show。**但全部 5 个样式表中 `[data-hidden]` 选择器命中数 = 0，bundle 中 `data-hidden` 仅此一处写入** —— 属性被切来切去，视觉上什么都不发生（`evidence/*-dom.html` 均为 `data-hidden="false"` + `transform:translate(0,0%)`）。
- `--site-header-top` 同理（effect 恒设 `"0px"`，无 CSS 消费方）。
- 旁支：`layout` 里有个 pathname effect —— `scrollY === --site-header-height(64) 时 scroll(0,0)`，修 Next.js 路由跳转恰好停在 header 高度的残位。

### A5. 供 CFE 参考的判断

Saronic 选择了"常驻 + 主题翻转"，而不是 anduril 的"比例让位"或 fugro 的"完全滚走"。对 B2B 询盘站，常驻 + `scrollY>0 → 实底发丝线`（vercel 模型，见 vercel DEEPDIVE）仍是成本最低的正确解；Saronic 值得抄的是 `onLeave` 的**临界翻转**（过了 hero 才给 header 上色）而不是它的死接线。

## B · 菜单开合动画

**结论：原生 `<dialog>` 右抽屉，进 500ms 签名缓动、出 250ms 更陡缓动、backdrop 同速淡入淡出；按钮图标不做 morph，卡片无入场 stagger，hover 揭示用非对称 125ms/250ms。**

### B1. 容器与几何（`css/3dcc14c5e1ce1ff3.css`）

```css
.SiteHeader_Menu{background:midnight300; color:sunlight100;
  inset:0 0 0 auto; height:100%; width:100%; animation-fill-mode:both!important}
@media(min-width:960px)and (max-width:1279px){.Menu{width:75%}}
@media(min-width:1280px){.Menu{width:clamp(960px,55%,100vw)}}     /* 1440 → 960px（≈67% 视口） */
.Menu::backdrop{background:rgba(0,0,0,.333)}
.Menu[open]{display:grid; grid-template-rows:64px 1fr auto;        /* 头/卡区/底栏 */
  animation:slideIn .5s cubic-bezier(.25,.25,0,1)}                 /* translateX(100%→0) */
.Menu[open]::backdrop{animation:fadeIn .5s linear}
.Menu[closing]{animation:slideOut .25s cubic-bezier(.5,0,.75,1)}   /* translateX(0→100%) */
.Menu[closing]::backdrop{animation:fadeOut .25s linear}
```

- 抽屉内部 `grid-template-rows:64px 1fr auto`：顶部行 = `Menu` mono 标签 + `aria-label="Close Menu"` 的 X 钮；中间 nav = 卡格 `padding:spacing-05(24px) gap:spacing-04(16px)`，1 列 → ≥640 2 列；底部 = MouseTracker `X=0 Y=0` 坐标读数。
- `[closing]` 属性由 JS 在调 `dialog.close()` 前挂上，跑完出场动画再真正关闭（`animation-fill-mode:both!important` 保最后一帧）。
- backdrop `rgba(0,0,0,.333)` 只遮左侧剩余区；公告条 z-index 2001 在菜单之上保持可见（`menu-open-1440.png` 实测）。
- Esc 关闭 = 原生 dialog 行为，零实现成本（`scenarios/menu-1440.json` 用 Escape 验证）。

### B2. 图标：不做 morph

- Header 的 MenuButton：`Menu`（caption-small mono）+ 静态两线 svg（`M4 12h24M4 20h24`，32×32，stroke 2，方帽）。open/close/常态 DOM 完全一致（四份 DOM diff 验证）。
- 抽屉内独立 X 钮（`M8 25 24.97 8.03M8 8l16.97 16.97`），位置与 header MENU 对齐。
- JS 里的 `rotate(-135deg)` 属于别的组件（accordion 加减号），与菜单按钮无关。**"菜单开=关"靠位置对齐 + 抽屉自含关闭钮，不做图标变换。**

### B3. 菜单卡（MenuLink）

```css
.MenuLink{aspect-ratio:1.75; border-radius:4px; display:flex; flex-direction:column;
  background:<per-card inline>; }
@media(pointer:fine){
  .MenuLink{opacity:.8; transition:.25s}
  .MenuLinkTitle[data-target=internal] svg{opacity:0; transform:translateY(5%); transition:.25s ease-in}
  .MenuLink hr{opacity:0; transition:.25s ease-in}
  .MenuLinkDesc{opacity:0; transform:translateY(5%); transition:.25s ease-in}
  .MenuLink:hover{opacity:1}
  .MenuLink:hover *{opacity:1; transform:none; transition:.125s ease-out}   /* 揭示快于隐藏 */
}
.MenuLink[aria-current=page]{box-shadow:0 0 0 4px midnight300,0 0 0 5px sunlight100}
```

- 六卡实色（DOM inline `background-color`）：Newsroom=`midnight100`、Vessels=`midnight200`、Mission=`sunlight100`（`data-dark=false` 反色文字）、Team=`sunlight300`、Contact=`twilight300`、**Join Our Mission=`sonar` 唯一高亮 = 全菜单唯一 CTA 卡**。
- 卡内：Title（`type--body-large`，space-between，右端 r=3 圆点 svg）+ `hr` 发丝线 + Desc（`type--body-small`，`text-wrap:balance`）。
- 揭示机制（仅 pointer:fine）：卡 80% 透明，dot/hr/desc 全 `opacity:0;translateY(5%)`；hover/focus 时 `.125s ease-out` 一起浮出，离开时 `.25s ease-in` 收回 —— **揭示 125ms、隐藏 250ms，与抽屉 500/250 正好反向**：容器快出，内容快显。
- `aria-current=page`：双层描边圈（4px 菜单底色 + 5px sunlight100）+ 白点 —— 当前页用"选中环"不用色块。

## D · 图片处理（"图和文共舞"的实现）

**结论：Saronic 的图从不被"框框起来"——图就是容器本身（照片铺满裁切 + scrim + 文字叠图），或者图出血贴视口边、文字留在页边距内；衔接用 scrim 溶进页面底色，不用边框、不用底卡。**

### D1. MediaCard —— "卡=图，字在图上"

```css
.MediaCard{position:relative; border-radius:spacing-03(8px); overflow:hidden;
  background:midnight400; isolation:isolate;
  box-shadow:0 1px 0 rgba(0,0,0,.04),0 8px 24px rgba(0,0,0,.08)}   /* 静止也有轻影 */
.MediaCard_Image{position:absolute; inset:0; object-fit:cover; z-index:0;
  transform:scaleX(var(--flip-x,1)); transition:transform .6s signature}
.MediaCard_Scrim{position:absolute; inset:0; z-index:1;
  background:linear-gradient(180deg,transparent 45%,rgba(0,0,0,.55))}
.MediaCard_Overlay{position:absolute; z-index:2;
  left:24px; bottom:24px; right:24px;                 /* ≥960 → 40px */
  display:flex; flex-direction:column; gap:8px}        /* Title(heading-large!) + CTA(caption mono+14px icon) */
.MediaCard:hover .Image{transform:scale(1.03)}         /* .6s 签名缓动 */
```

- 叠字直接压图：标题用 `type--heading-large`（32→64px），压在一个 `transparent 45% → rgba(0,0,0,.55)` 的底渐变上 —— 字可读靠 scrim 不靠底板。
- `home-1440-dom.html` 实测：Corsair/Mirage `data-aspect="4/3"` 两卡并排 + Marauder `data-aspect="21/9" data-span="full"` 通栏（<960 退化为 4/3）——**同一套件通过 aspect 属性排出 2+1 网格**。
- `--flip-x:-1`（Mirage 卡 inline）：图片水平镜像，让船头朝内对着网格 —— 构图级微操，一行变量。
- hover：`scale(1.03)` + 阴影升到 `0 2px 0 .06, 0 14px 36px .16` + CTA 文字 roll（`.3s/.6s` 接力缓动）。

### D2. split-image-bleed —— 图出血到视口边

```css
.HomeSection[data-layout=split-image-bleed-*]{padding-inline:0; padding-block:0}   /* 连 section padding 都不要 */
  .Inner{grid-template-columns:1fr 1fr; max-width:none; gap:0; min-height:720px}   /* ≥960 */
  .Content{padding-inline:page-margin / spacing-08; padding-block:spacing-section;
           max-width:600px; align-self:center}                                      /* 文字留在 margin 里 */
  .Visual{aspect-ratio:4/3}                                                         /* 移动 */
  @media(min-width:960px){.Visual{aspect-ratio:auto; height:100%; align-self:stretch}}
.MediaImage[data-mode=fill] img{
  object-fit:cover; object-position:bottom center;
  @media(min-width:960px){ object-fit:contain;                                       /* ← 桌面反而 contain */
                           object-position:bottom var(--media-fill-align-x,left) } }
```

- 反直觉的关键招：**移动端图 cover 裁满，桌面端图 contain 贴边底对齐** —— 大图（产品渲染）在桌面是"完整呈现 + 靠 section 侧缘落地"而非裁切铺满，`--media-fill-align-x` 由 `split-image-bleed-left/right` 决定靠哪边。
- `MediaImage[data-mode=card]` = 8px 圆角 + overflow hidden —— "卡模式"和"出血模式"是同一个媒体组件的两个档位。

### D3. video-background-left —— 字直接压视频

```css
.HomeSection_BackgroundScrim{position:absolute; inset:0;
  background:linear-gradient(90deg,rgba(22,32,41,.78) 0,rgba(22,32,41,.55) 45%,rgba(22,32,41,.15))}
.HomeSection[data-layout=video-background-left] .Content{max-width:560px}
.HomeSection[data-layout=video-background-left] .Inner{min-height:360px→480px→640px}
```

- 横向渐变（左 78% → 中 55% → 右 15%）只压文字所在左半，右侧视频保持明亮 —— scrim 方向跟文字方向走。
- 文字（eyebrow+h2+body+CTA）无卡无底，直接排在视频上。

### D4. 溶边 scrim 语法（全站三套，均可抄）

| 场景 | 渐变 |
|---|---|
| hero（移动） | `180deg, rgba(22,32,41,.5) 0 → .2 30% → .2 45% → .9 70% → #162029 90%` —— 底部直接渐落到页面底色 |
| hero（桌面 fixed 底） | `180deg, .5 0 → .2 35% → .2 60% → .65` |
| 视频 section | `90deg, .78 0 → .55 45% → .15` |
| MediaCard | `180deg, transparent 45% → rgba(0,0,0,.55)` |

- 规律：**顶部深保文字、底部渐落到页面底色**，所以 section 之间看不到图与底的接缝。CFE 用暖白纸底时把落点换成 `#162029` 对应的暖白色即可。
- 附加：浅页（mission/team）底铺 `40×40 inline SVG 方格纸`（sunlight100 低透明）—— "工程图纸"质感零素材成本。

### D5. 其他

- 内嵌内容视频（`HardwareVideo/SoftwareVideo`）：`border-radius:4px` + `object-fit:cover` —— 小半径裁切，无边框。
- 首页视频底：`position:fixed` `width:var(--100vw)`（JS 实测 vh/vw 变量绕移动 URL bar）；≤959 整个 fixed 层 `display:none`，移动用 hero 内置 video（`min-width:175%` 裁切，桌面 130%）。

## E · 滚动叙事

**结论：滚动触发（IntersectionObserver `data-shown`）为主、GSAP scrub 只用在首页两层、锚点章节只有 careers/portalpha 两处——hover 不负责叙事，只负责卡片揭示。**

### E1. reveal 机制（滚动触发，非 hover）

```css
.PageTitle{clip-path:inset(0 0 100%); transform:translateY(100%)}
.PageTitle[data-shown=true]{clip-path:inset(0 0 0); transform:translateY(0);
  transition:1s cubic-bezier(.25,.25,0,1); transition-property:clip-path,transform}
.PageContent[data-shown=false] .Inner{opacity:0; transform:translateY(10vh)}
.PageContent[data-shown=true]{transition-delay:1s}
.PageContent[data-shown=true] .Inner{opacity:1; transform:translateY(0); transition:all 1s signature}
.Page_Headline{clip-path wipe; transition:1.1s signature; transition-delay:.15s}   /* portalpha */
```

- `data-shown` 由 IntersectionObserver 驱动（TEARDOWN §5.2）；`data-shown=false` 时容器 `overflow:hidden` 防闪。
- 揭幕序列：PageTitle 擦幕 1s → PageContent 整体 `translateY(10vh)→0` + fade，延迟 1s —— **先揭题，再起内容**，一段固定编排在每个内页重复。

### E2. 首页的两条 scrub（GSAP ScrollTrigger，`page-*.js` + `layout-*.js`）

```js
// home hero（page chunk）
timeline({scrollTrigger:{start:0, end:()=>clientHeight, scrub:true}})
  .to(VideoBackground, {opacity:.2},0)    // fixed 视频底随滚动压暗
  .to(".LogoContainer", {opacity:0},0)    // 巨标淡出
// header 主题（layout chunk，见 §A3）—— 同区间 0→100vh 底边+logo
```

- `requestHeroExitScroll` → `gsap.to(window,{scrollTo:#capabilities, duration≈速度自适应, ease:power3.inOut})`，scrollTo 前 `scrollSnapType="none"`、完成后还原 —— **程序化滚动时临时关 snap**。
- 勘误：hero `scroll-snap-align:start` 存在，但全 CSS/JS 中没有 `scroll-snap-type` 容器声明（仅 Tailwind `--tw-scroll-snap-strictness` 默认值），**snap 实际是死声明**；真实机制就是上面两条 scrub，不做分段吸附。
- ScrollSmoother 打进 bundle 但 DOM 无 `smooth-wrapper`（TEARDOWN 已证未激活）。

### E3. 章节/TOC 机制（两处，各一套）

- **careers**（`evidence/careers-dom.html`）：`<nav data-sticky="true" aria-label="Careers page sections">` = 5 条 `type--caption-small` 锚链（The Work/Our Values/Locations/Benefits/Open Roles），`scroll-margin-top:var(--site-header-height)` 让锚点落在 header 下；各 section 头 `SectionMarker` = `01` 序号 + 标签（mono），标题 `display-small`。**TOC = 粘性 mono 锚链 + 章节序号，不做 scrollspy 高亮**（DOM 无 active 类证据）。
- **portalpha**（编辑长文）：`aside.SectionAside{position:sticky; top:spacing-09(64px); align-self:start}` ≥960 —— sticky 侧栏跟读；`SectionNumber{display:block; font-size:clamp(72px,10vw,128px); color:rgba(22,32,41,.18); font-variant-numeric:slashed-zero}` —— **18% 透明的巨型章节号**压栏边；正文带 `EndnoteLink/EndnoteBacklink`（学术引用装置）与 `StatGrid` 数字格。
- 对比：滚动叙事强度 fugro（章节 TOC + scrollspy）> saronic（粘链/幽灵章节号）> vercel（≈无）。

## F · Footer 注意力分配

**结论：视觉中心是"巨号导航链接"——`type--heading-large`（32→64px）当 footer 链接字号；1px cell 网格分区；右下角 MouseTracker 坐标 HUD；唯一彩色元素 = 招聘 sonar 按钮。**

### F1. 结构（`css` + `evidence/home-1440-dom.html`）

```
SiteFooter_Background: midnight400 position:fixed inset:0 visibility:hidden   /* ≥640 存在的全视口底层 */
Grid: display:grid; gap:1px;  cells bg=midnight300 + outline:1px #424a52      /* 漏缝成发丝分割 */
≥1280: rows 1fr 1fr .667fr × cols 1fr 1.5fr 1.5fr
```

| cell | 位置（≥960） | 内容 |
|---|---|---|
| Logo | col1 row1 | 居中大 logo（整块是链回首屏的 a）；`©2026` 只 <640 显示 |
| Join Our Mission | col1 row2 | caption 眉 + `title-small medium` 推销句（`max-width:18ch`）+ sonar `View Job Openings` 按钮（`margin-top:auto` 沉底） |
| Address | col1 row3 | `Built in Texas`(title-small medium) + Privacy（op.5，margin-top:auto）+ © |
| Technology | col2 rows1–3 | eyebrow `data-space=extra`(mb 64px) + 链接 Vessels/Echelon |
| Company | col3 rows1–3 | 同构：Mission/Team/Newsroom/Contact + connect（LinkedIn/X 图标） |
| More | 仅 <960 | 移动版全量导航 + connect |
| MouseTracker | col3 右下角 align-end | `X=0 Y=0` mono 实时坐标 + 32×8 装饰 svg |

### F2. 注意力参数

- PrimaryNav 链接 = `type--heading-large`（32→64px、lh1.12、ls−.02em）——**页脚最大字**，`opacity:.5 → hover .75 → aria-current 1`，列距 `gap:spacing-03/04/05`（8/16/24）。
- cell 眉标 = `caption-small` mono，`color:sunlight100-50`（50% 白），下距 `spacing-05(24)` 或 `data-space=extra → spacing-09(64)` —— 长间隔把链接组往下推，强化"眉标是弱标签、链接是主体"的层级。
- cell padding `spacing-07(40px) var(--page-margin)`；社交链 `margin-top:spacing-08(64)`。
- 无订阅框、无回顶、无 logo 墙 —— footer 三件事：**去哪（巨字链接）、加入我们（唯一 sonar CTA）、工程感签名（MouseTracker + Built in Texas）**。
- ≤639：单列，Background 层 `display:none`，MouseTracker/Technology/Company 隐藏（只留 More+Join+Logo+Address）。

## CFE 可抄清单（按六轴映射）

- **A · header**：抄"常驻 sticky + 主题翻转"的**判断**，不抄实现 —— CFE 不需要 GSAP。等价物：`scrollY>0` 加实底发丝线（见 vercel 方案）+ 深底 section 页按页注入 `--fg-color`。学 saronic 的 `--announcement-bar-height` CSS 变量编排（公告条高度进布局变量，hero 内容 `top:calc(var(--announcement-bar-height)+…)`），比硬编码 margin 干净。**别学**：把方向检测接上 UI 又不给它写样式（死接线就是这么来的）。
- **B · 菜单**：移动全屏菜单直接抄 dialog 方案——原生 `<dialog>`（免 backdrop/焦点管理）+ 右抽屉 `.5s cubic-bezier(.25,.25,0,1)` 进 `.25s cubic-bezier(.5,0,.75,1)` 出 + backdrop `rgba(0,0,0,.333)` `.5s/.25s linear`。卡式菜单格 `aspect-ratio:1.75 radius:4px` + hover 揭示 `.125s ease-out`（揭快隐慢），RFQ 卡做唯一 accent 底。图标不必 morph —— 抽屉内对齐位置放 X 即可。
- **C · 密度**：section 文案上限抄数字 —— eyebrow ≤3 词、标题 ≤6 词、正文 ≤1–2 句（≤18 词）、每 section 至多 1 CTA；行宽 40–56ch 分档硬锁；`spacing-section` 用 80→120→160；页边 16→24→32→40；页标底下敢压 80–160px 再接导语。
- **D · 图**：三条直接可用 —— ①卡=图：照片铺满 + `radius:4–8px` 裁切 + `180deg transparent 45%→rgba(0,0,0,.55)` scrim + 左下角叠字（24→40px 内边距），hover `scale(1.03) .6s`；②scrim 底部渐落到页面底色（把 `.9→#162029` 换成 CFE 暖白）消掉图/底接缝；③分栏 bleed：section padding 清零、图贴视口边、文字守 page-margin，大图 `object-fit:contain` 底对齐不裁切。附赠 `--flip-x` 镜像和 40px 方格纸纹理。
- **E · 叙事**：抄 reveal 不抄 scrub —— `data-shown` + `clip-path:inset(0 0 100%)→0` 揭题（≤1.2s）+ 内容 `translateY(10vh)→0` 延迟跟进，IntersectionObserver 一次到位；页内章节用 careers 式 sticky mono 锚链（`scroll-margin-top:var(--header-height)`）+ `01` 序号标记，或 portalpha 式 sticky aside + 18% 透明巨型章节号（`font-variant-numeric:slashed-zero`）。scroll-snap/scrub 全跳过（CFE 禁令 + saronic 自己也是死接线）。
- **F · footer**：注意力公式 = **链接用显示字号当主角**（CFE 可用 heading 档而非 14px 目录）+ `gap:1px` cell 网格分区 + 一个 accent CTA cell + 法律/Privacy 压 cell 底（`margin-top:auto` + opacity .5）。MouseTracker 这类"工程签名件"可选——CFE 若要放，坐标换成"经纬度/工厂位"语义更贴海工。

## 三案横向备注（saronic × anduril × fugro）

> 基准：anduril DEEPDIVE（header 比例让位+frosted/scramble/文字动画三原语）、fugro DEEPDIVE（header 不 sticky/章节 TOC/白底巨字 footer）。以下只列 **saronic 独有且 CFE 可参考** 的点。

1. **`gap:1px` cell 网格是唯一"机制级"发丝线**。anduril/fugro 的 1px 分割靠逐元素 border；saronic 用 `display:grid;gap:1px;背景=border色;cell实底` 一条规则同时产出所有分割 —— footer/规格格/accordion 同构，天然无双线、天然等宽。CFE spec-grid 直接换这个写法，比 anduril 式逐边声明更省事。
2. **菜单本身是"色卡矩阵"**。anduril = hover 下拉 + 全屏 blur overlay；fugro = 平铺；saronic = `<dialog>` 抽屉装 6 张**预着色的实体卡**（aspect 1.75 + 各卡一个 token 底色 + 唯一 accent CTA 卡）。B2B 站移动菜单"6 入口 + 1 CTA"可直接套版。
3. **header 主题翻转的临界点是"一屏"**。anduril 30px 阈值上 frosted；vercel `scrollY>0` 上实底；saronic 用 `end:clientHeight` —— **滚完整个 hero 才让 header 上色**，临界感最克制，且 onLeave 是硬切不是渐变（scrub 部分只负责 logo/底边渐进）。
4. **公告条↔header↔hero 巨标三方联动入场**（`.6s power2.out` 同 timeline，`--announcement-bar-height` 变量下推巨标）—— anduril/fugro 都没有"顶部条 + header + hero 元素一支编舞"的实现，这是 saronic 独有编排。
5. **`object-fit` 按断点换档**：同一张图移动 `cover` 裁满 ↔ 桌面 `contain` 贴边落地（`object-position:bottom var(--media-fill-align-x)`）—— 小屏保冲击、大屏保完整，anduril 一刀切 cover，fugro 没有 bleed 分栏。
6. **scrim 渐落到"页面底色"**：saronic hero 底部 `.9→#162029` 五档渐落让视频无接缝溶进下一屏；anduril 是 `multiply` 黑化溶边（透明→#010101），fugro scrim 类似 anduril。saronic 版对"浅底站"更友好（换成暖白即可）。
7. **幽灵章节号**（`clamp(72px,10vw,128px)` + `rgba(22,32,41,.18)` + `slashed-zero` + sticky aside）—— fugro 的章节感靠 TOC 锚链命名，saronic 靠巨号数字本身当页面构件；长文页（CFE 集团业绩叙事）此招直接可用。
8. **MouseTracker 坐标 HUD**（header/menu/footer 三处的 `X=0 Y=0` mono 实时读数）—— 独有的"仪器感"签名件，成本极低（一个 mousemove → 两个 mono span）。
9. **反面教材**：`data-hidden` 死接线 + `scroll-snap-align` 死声明 —— 两个"机制留了但样式没接"的实例，提醒 CFE 改版验收要查"属性切换了但视觉没变"的半成品。
10. **announcement ticker 四主题 + 隐藏滚动条**（white/midnight/sonar/beacon 全色板、`overflow:auto;scrollbar-width:none`、右 × `12/20px padding`）—— anduril/fugro 无对应件；CFE 若放集团资质 ticker 这是现成结构。
