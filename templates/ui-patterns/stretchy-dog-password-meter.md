# 会伸长的腊肠狗密码强度条

一行定位：**指标即身体**，长度一变，角色就真的跟着长；比任何进度条都更直观。来源：[Ramin Nasibov 的视频帖](https://x.com/RaminNasibov/status/2111194691303596460)（2026-10-17，约 2.5k 赞、584 收藏）。实现工具未公开（回复里有人猜 Rive，未证实）。可运行的最小演示：[`snippets/stretchy-dog-password-meter.html`](./snippets/stretchy-dog-password-meter.html)。

## 原作拆解

- 卡片「Reset password」，副标题「Make it long, you weakling」，黑色 Reset 主按钮 + Cancel 文字链接。
- 每输入一个字符，输入框变宽，**狗身体中段拉伸到与输入框完全等宽**，头和尾巴分别贴住两端。
- 表情五档：不爽 → 惊讶 → 微笑 → 得意 → 吐舌开心。
- 提示文案逐级升级：红色「Password strength: pathetic / still weak / ok for a noob / not bad, weakling」→ 绿色「damn, solid / finally good enough」。
- 清空后立刻弹回最短状态。

## 流程

1. **选一个指标。** 只映射一个连续量（这里是长度）。多个指标叠在同一个角色上会失去“一眼看懂”的力量。
2. **定阈值与档位。** 例如 0–5 / 6–9 / 10–13 / 14–17 / 18–21 / ≥22 字符对应 6 档文案、5 档表情。第一档绿色阈值 = 产品真正的最低要求，之后是“奖励区”。
3. **让隐喻真的长。** 输入框宽度绑定内容长度，角色的可伸缩段与输入框同宽，头尾固定尺寸（9-slice 思路）。
4. **写语气文案。** 文案随档位升级，红到绿；毒舌程度要与品牌匹配。
5. **给奖励态。** 达标后表情与颜色明显变化（吐舌、绿色），让用户愿意多打几个字。
6. **验收**（见末尾清单）。

## 机制依据

- **宽度：** `input { width: calc(var(--len) * 1ch + padding) }`，用 `ch` 让宽度与字符数线性；设 `min-width` / `max-width: 100%`，超出后宽度停止增长、角色停在最长态，输入框内部正常滚动。密码框里的圆点与 `ch` 宽度不完全一致，以实际渲染宽度（`ResizeObserver` 或 `scrollWidth`）为准更稳。
- **身体：** SVG 三段：头（固定）+ 身体（`<rect>` 或 path 的 `scaleX` / 宽度跟随）+ 尾巴（固定，`translateX` 跟随末端）。Rive 做法：一个 `length` number input 驱动骨骼拉伸，一个 `mood` 状态机切表情。
- **表情：** 阈值切换离散状态（不要插值嘴型，中间态容易诡异）。切换时可以加 100–150ms 的小弹跳。
- **强度：** 鼓励长度时直接用长度；需要更真实的强度时用 zxcvbn 一类的熵估计，但**角色仍只映射一个分数**。
- **动画：** 宽度过渡 120–200ms ease-out；清空时弹回可以稍快。`prefers-reduced-motion: reduce` 时取消过渡与弹跳，只保留离散的表情与文案切换。
- **可访问性：** 强度文案放在 `aria-live="polite"` 的区域，并通过 `aria-describedby` 关联到输入框；角色本身 `aria-hidden`。颜色之外要有文字（红绿色盲）。

## 回复区洞察

- 「用视觉判断强度，比任何 meter 都更有冲击力」（[@Fasil5255](https://x.com/Fasil5255)）。
- **里程碑目标：** 在路径上放几个食盆，狗够到第一个 = 最低要求，再往后是 bonus（[@Varun_1004](https://x.com/Varun_1004)）。适合把“达标”和“更好”分开表达。
- **反对意见：** 强迫长而复杂的密码是家长作风（[@notdenveous](https://x.com/notdenveous)）。所以它应当**鼓励长度，不应当拦人**：最低要求以外一律只奖励、不阻止提交。
- 有人觉得拉长后的笑脸诡异（[@michaelflux](https://x.com/michaelflux)，10 赞）：**表情设计决定成败**，最长态之前先拿真人看一眼。

## 边界

- 用在 playful / 消费级 / 品牌允许调侃的表面；银行、医疗、企业后台换成普通强度提示。
- 毒舌文案永远不针对用户本人以外的身份特征；面向多语言时每种语言单独写，不直译。
- 最低要求明确写出来（例如「至少 10 个字符」），不能只靠角色暗示。
- 不在同一视图再叠第二个动态角色或大气动效。

## 消费项目验收

- 输入、删除、粘贴、清空时身体与输入框始终等宽，头尾不脱节；到 `max-width` 后不溢出卡片。
- 320px 窄屏可用；深浅色可读；键盘可完成全部操作。
- reduced-motion 下无过渡，状态仍正确。
- 屏幕阅读器能听到档位文案变化，不会每个字符都播报（对 live 区域节流）。
- 文案与表情在每个阈值上切换正确（含边界值）。
