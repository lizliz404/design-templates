# ThreeUI — 单个 Community hero

**What：** 从 [threeui.com](https://threeui.com/) / [MengTo/threeui](https://github.com/MengTo/threeui) 的 **Community** 目录抄 **一个** 免费 hero 到消费项目。  
**Why：** 160+ 免费变体是浏览面，不是 pack 库存。主站总目录（约 410）含 Pro，不要混称。  
**When：** 叙事 landing / 创意工具入口，且运动本身是产品表面。  
**Not：** 数据密集后台、RFC/IA 说明图、HTML deck 背景、为了显得专业而加的 Three 循环。先读 [`../decks/visual-economy.md`](../decks/visual-economy.md)：解释机制默认 prose → ASCII → Mermaid；React/Three 只给产品表面。

## 取件

1. Community 里打开 **一个** hero，用 Code/source，不要远程缩略图（README：预览图不可再分发）。
2. 先对齐页面 layout，再调 theme / 光照 / hue-saturation-brightness / speed。
3. `prefers-reduced-motion`：静态海报或无运动 CSS；不要只关一半粒子。
4. 许可证：Community 应用/组件/作者图为 **MIT**（[`LICENSE`](https://github.com/MengTo/threeui/blob/main/LICENSE)）。字体与运行时另算。随交付留 MIT notice。
5. **Pro / MCP / skills / 折扣包：不进 pack，不装进本仓库。**

## 禁止

- 164 条整目录、`node_modules`、CLI、付费 Pro
- 用 ThreeUI 画架构图、权限模型、时序
- 与 thinking-orb 或 Paper live shader 同屏叠第二套 WebGL/WebGPU 大气
