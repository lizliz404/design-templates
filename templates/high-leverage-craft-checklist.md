## 三问过滤器（做之前先过）

1. **改情绪或决策吗？** 纯装饰 ≠ 杠杆。
2. **成本在「一杯咖啡 → 一个下午」吗？** 再大就走正式 ROI，别冒充四两拨千斤。
3. **3 秒内可感知，或卡在关键路径**（首次激活、付费、出错、离开）？不在关键路径上的精致，多半是自嗨。

通不过就砍。本手册按**机制**分组；`frontend` `backend` `growth` `ops` `copy` 只作次要标签。

## 一、等待：把「未知多久」换成「我知道在发生什么」

### 1. 骨架屏代替裸 Spinner `frontend`

**是什么**：用接近真实布局的浅色占位，而不是无限转圈。  
**为何杠杆**：同样等待，焦虑差在「有没有终点形状」。转圈 = 未知；骨架 = 「内容长这样，马上到」。  
**怎么落地**：按关键页面真实栅格画 3–5 块灰条；列表行高与真数据一致。  
**反模式**：骨架和真布局对不上（跳变比 spinner 更糟）；每个按钮旁都转圈。  
**开火路径**：首屏、Dashboard、列表页加载。

### 2. Optimistic UI（可回滚的先成功） `frontend`

**是什么**：点赞、勾选、排序、发送——先更新界面，后台再同步；失败再回滚并提示。  
**为何杠杆**：把 200–400ms 网络感知压成「零延迟」，专业感来自手感不是功能清单。  
**怎么落地**：React Query / SWR `onMutate` + 快照回滚；不可逆操作（支付、删库）不要乐观。  
**反模式**：对钱、权限、合规写路径做乐观；失败无回滚、无错误文案。  
**开火路径**：高频低风险交互。

### 3. 诚实的「劳动幻觉」进度文案 `frontend` `copy`

**是什么**：长任务不写 `Loading…`，写阶段事实：「正在比对航司」「生成第 3/5 段」「解析 PDF 第 12 页」。  
**为何杠杆**：Labor Illusion——看见系统在干活，满意度往往高于「更快但一片空白」。Kayak、多数 AI 长任务都靠这招。  
**怎么落地**：把后端阶段或估计步骤映射成 3–7 条人话；能量化就量化，别瞎编百分比。  
**反模式**：假进度条冲到 99% 卡住；编造不存在的步骤。  
**开火路径**：搜索聚合、导出、AI 生成、大文件处理。

### 4. 能本地先出的结果，别干等接口 `frontend`

**是什么**：过滤、搜索、排序——有缓存/本地数据就先渲染，远端结果到了再修正。  
**为何杠杆**：800ms 转圈 vs 立刻可见（哪怕标「可能不完整」），体感差一个数量级。  
**怎么落地**：先 `filter(localCache)`；远端回来后 merge，并弱提示「已与服务器同步」。  
**反模式**：把过期数据当真理且不标注；权限敏感数据勿本地先行。  
**开火路径**：设置页、资源库、带筛选的表格。

## 二、可逆：用「可反悔」换用户胆量

### 5. Undo Toast 优于确认弹窗 `frontend` `copy`

**是什么**：破坏性操作先执行，底部「已完成 · 10 秒内撤销」；不要动不动 `Are you sure?`。  
**为何杠杆**：损失厌恶——阻断确认制造犹豫，撤销把成本挪到事后，转化与情绪双赢（Gmail 撤回发送是教科书）。  
**怎么落地**：软状态挂 10–30s；过期再硬提交。支付、不可逆合规动作仍用强确认。  
**反模式**：一切都 Undo（用户不知是否真生效）；Undo 窗口短到点不到。  
**开火路径**：删除、归档、取消订阅前一步、发送邮件。

### 6. 自动保存 + 极弱「已保存」 `frontend`

**是什么**：去掉显式 Save 心智负担；右上角一行小字即可（Notion 式 `All changes saved`）。  
**为何杠杆**：用户怕丢稿；你用后台 debounce 换安心，比任何「别忘了保存」文案都强。  
**怎么落地**：输入 debounce 500–1000ms 写 draft；冲突时提示「他人已更新」而非静默覆盖。  
**反模式**：无反馈的静默保存（用户不敢关页）；每键一次全量请求。  
**开火路径**：编辑器、表单草稿、配置页。

### 7. Soft-delete：`deleted_at` 比客服便宜 `backend`

**是什么**：破坏性删除默认进回收站 15–30 天，不是物理抹掉。  
**为何杠杆**：一行字段换「删错了」客诉与信任崩盘；实现成本接近零。  
**怎么落地**：查询默认 `WHERE deleted_at IS NULL`；管理端提供恢复；到期 job 再硬删。  
**反模式**：GDPR/用户要求删除时还软留 PII；没有真正的硬删路径。  
**开火路径**：项目、文件、客户记录、账单附件。

## 三、峰终：开场与离场决定记忆

### 8. 预填示例数据，别扔空白 Dashboard `growth` `frontend`

**是什么**：新账号自带 demo 项目 / 看板卡片 / 假客户，让用户「从 1 改」而不是「从 0 想」。  
**为何杠杆**：空页第一反应常是「这东西对我没用」；Aha 被前移到改第一条示例。  
**怎么落地**：注册后写入只读或可删的 seed；空状态 CTA 写「用示例试试」或「导入自己的」。  
**反模式**：示例像广告、删不掉、和真实数据模型对不上。  
**开火路径**：Onboarding 首屏、空 workspace。

### 9. 完成态的克制庆祝 `frontend` `copy`

**是什么**：清空列表、首次导入成功——200ms 微动效或一句人话，不要彩带轰炸。  
**为何杠杆**：峰终定律——结尾小峰值会被记成整段体验；过度庆祝像诈骗页。  
**怎么落地**：Linear / Superhuman 量级：短文案 + 可选微动效；尊重 `prefers-reduced-motion`。  
**反模式**：每次勾选待办都放烟花。  
**开火路径**：首次价值达成、导入完成、里程碑任务。

### 10. 主动设计「离开」 `growth` `copy`

**是什么**：取消订阅 / 删账号时问一句真实原因，并给一个体面出口（降级、暂停、导出数据）。  
**为何杠杆**：不只是挽留转化；记忆里留下「最后还被认真对待」，影响口碑与回流。  
**怎么落地**：单选原因 + 可选自由文本；一键导出；别做黑暗模式多步刁难。  
**反模式**：假客服聊天关卡；藏取消按钮。  
**开火路径**：Billing portal、账号删除。

## 四、系统怎么说话（Microcopy）

### 11. 错误文案 = 发生了什么 + 下一步 `copy`

**是什么**：禁止裸 `An error occurred` / 内部错误码甩给用户。  
**为何杠杆**：每次报错都是信任投票；说清「怎么办」比漂亮 UI 更能止损流失。  
**怎么落地**：模板：`[具体事实]。[可选原因]。[动作：重试 / 换支付方式 / 联系支持并附 request id]`。  
**反模式**：把 stack trace 给终端用户；所有错误同一句「请稍后重试」。  
**开火路径**：支付失败、权限不足、校验失败、5xx。

### 12. 按钮写后果，不写礼貌 `copy`

**是什么**：`Delete this project forever` / `Yes, cancel my subscription` 优于 `OK` / `Confirm`。  
**为何杠杆**：多几个字，少一次误点心跳骤停；文案即安全护栏。  
**怎么落地**：主按钮 = 动词 + 对象 + 不可逆时加 forever/cannot undo。  
**反模式**：红按钮写「确认」却不知确认什么。  
**开火路径**：破坏性 modal、checkout、权限授权。

### 13. 空状态 = 教程 + CTA，不是「暂无数据」 `frontend` `copy`

**是什么**：空列表写清「这里将来是什么」+ 一个可点主 CTA + 一句有品牌口吻的话。  
**为何杠杆**：高手把空状态当激活漏斗的一环；新手当 bug。  
**怎么落地**：1 主 CTA + 1 示意图或短例 + 可选次要「查看文档」。  
**反模式**：只有插画没有动作；三个同等 CTA 抢焦点。  
**开火路径**：首次进入模块、过滤结果为空。

## 五、信任：暴露可控，比假装完美更便宜

### 14. 公开 Status Page `ops` `growth`

**是什么**：Better Uptime / Instatus / 自建一页，展示组件状态与事故说明。  
**为何杠杆**：反直觉——愿意公开故障的产品显得更可控；B2B 采购常直接问。  
**怎么落地**：监控关键 URL + 支付 webhook；事故时写人话时间线，不是「正在调查」糊弄。  
**反模式**：状态页永远绿但产品明明挂了（信任一次烧完）。  
**开火路径**：营销站页脚、客户成功话术、事故沟通。

### 15. 人话 Changelog，当活着的证明 `growth` `ops`

**是什么**：每周/每两周用人话写「做了什么、为何」；不是 git log 倾倒。  
**为何杠杆**：产品仍在维护的信号；邮件/RSS 是廉价再激活触点。  
**怎么落地**：每条 PR 或每周五写 3–5 条用户语言；订阅可选。  
**反模式**：内部代号、无用户价值的重构流水账。  
**开火路径**：应用内「What's new」、邮件、公开 `/changelog`。

### 16. 事务邮件走接近纯文本 `copy` `growth`

**是什么**：收据、密码重置、发票——像真人邮件，少花哨营销 HTML。  
**为何杠杆**：送达率与「这是办事不是轰炸」的感知；Stripe / Basecamp 系长期如此。  
**怎么落地**：Resend / Postmark；必须 HTML 时也提供干净纯文本 part；品牌克制。  
**反模式**：收据里塞三张促销 banner。  
**开火路径**：支付成功、发票、安全通知。

## 六、分发与定价（只留高信号）

### 17. 分享链接的动态 OG 图 `growth`

**是什么**：每篇内容 / 每个公开页一张定制 OG（`satori` / `@vercel/og` / CF Workers 绘图）。  
**为何杠杆**：链接在 X/Slack/微信展开时的封面，几乎决定点不点；默认截图等于浪费展示位。  
**怎么落地**：模板：标题 + 品牌色 + 关键数字或作者；缓存生成结果。  
**反模式**：每页随机渐变无信息；图上字多到缩略不可读。  
**开火路径**：博客、公开报表、分享页、文档站。

### 18. 定价三档：锚定要诚实 `growth`

**是什么**：低 / 推荐（标 Most Popular）/ Enterprise（Contact us）——用对比降低决策成本。  
**为何杠杆**：锚定与诱饵是真机制；但「所有 SaaS 必须三档」是 cargo cult。  
**怎么落地**：中间档对应你真正想卖的；功能差异用用户语言；企业档写清触发条件（SSO、发票、SLA）。  
**反模式**：两档硬凑第三档垃圾套餐；「最受欢迎」无人选还硬标。  
**开火路径**：`/pricing`；已有付费意向流量时再打磨。

### 19. 「Powered by」只在可分享产物上 `growth`

**是什么**：用户对外分享的页面/表单/小部件底部自然水印。  
**为何杠杆**：零付费渠道的展示位；前提是不违和、可关掉（付费去标）。  
**怎么落地**：分享页 footer 一行；付费计划可移除。  
**反模式**：私密 B2B 后台每页强塞水印（惹厌恶、无传播）。  
**开火路径**：公开表单、文档站点、客户门户分享页。

### 20. 等待名单「分享插队」——仅冷启动 `growth`

**是什么**：分享链接可提前解锁或加积分。  
**为何杠杆**：把获客成本转成社交货币；产品未验证时有用。  
**怎么落地**：唯一 referral code；防刷（同设备/同 IP 限额）；说清奖励。  
**反模式**：已有稳定付费后还靠插队制造饥饿感（透支信任）。  
**开火路径**：预发布落地页。

## 七、专业手感（按产品选型，不是标配教条）

### 21. Cmd/Ctrl+K：密度够再做 `frontend`

**是什么**：命令面板跳转、搜实体、跑高频动作。  
**为何杠杆**：对每日使用的 B2B/工具型产品，是「这团队懂我」的信号；实现可用 cmdk 等，成本不高。  
**怎么落地**：先覆盖导航 + 3–5 个最高频命令；模糊搜标题即可。  
**反模式**：内容站/一次性落地页硬上 Cmd+K；面板里塞从未用过的命令。  
**开火路径**：日活工具、后台、IDE 类产品。

### 22. 微反馈三档（手感纪律） `frontend`

**是什么**：≤100ms 按下态；≤300ms 面板过渡；≥1s 必须给进度（骨架/文案/条）。  
**为何杠杆**：静默超过约 400ms，用户开始怀疑「点没点到」。  
**怎么落地**：全局约定；长任务复用条目 3。  
**反模式**：300ms 动画拖所有点击；无障碍用户未提供降级。  
**开火路径**：全站交互基线。

### 23. Hover 感知，Click 执行 `frontend`

**是什么**：只需「看看有什么」的触发器——下拉选项、tooltip、行内快捷操作、二级信息——鼠标悬停短暂停留（hover intent 150–300ms）后直接展开；click 只留给真正执行动作的确认（提交、删除、保存、跳转、打开复杂面板）。  
**为何杠杆**：「为了看看而 click」是白收的交互税。工作台/表单类产品里这类触发器密度极高，省一次点击 × 每天几百次，整个界面手感轻一个量级。  
**怎么落地**：hover intent 延迟 150–300ms（划过不弹，停留才弹）；展开用 opacity + transform 过渡 150–250ms，不硬切；移开即收（留 ~100ms 缓冲防边缘抖动）；触屏无 hover，保留 click 兜底；`prefers-reduced-motion` 下改即时显隐。  
**反模式**：hover 直接触发不可逆动作（支付、删除）；零延迟划过就弹，鼠标路径上全是闪现面板；把唯一入口藏进 hover 层（可发现性反而塌——核心 CTA 必须裸眼可见）；移动端照搬。  
**开火路径**：导航/账户下拉（如「授权广告账户」展开 Meta / YouTube 选项）、表格行内快捷操作、信息 tooltip、AI 能力说明。

### 40. 禁止纯白 / 纯黑铺底 `frontend`

**是什么**：页面底、卡片、侧栏、弹层不要用 `#FFFFFF` / `#000000`，也不要用等价的 `oklch(1 0 0)` / `oklch(0 0 0)` 实底。浅色用带一点色相的纸色（L ≈ 0.96–0.97，C ≈ 0.003–0.008）；深色用抬起来的墨底（L ≈ 0.17–0.22），不是洞。  
**为何杠杆**：纯白对纯黑是显示器能给的最大刺激，长时间盯表会刺、会累；同时也是「没调过色」的浏览器默认。改一组 token 一杯咖啡，护眼和「做过设计」一起到。  
**怎么落地**：`paper` / `--background` 带色相；`card` 比 paper 略亮，但 **L < 1**；正文 ink **L ≥ 0.22**（近黑带色相，不是 `#000`）；dark `--background` **L ≥ 0.17**。禁 `bg-white` / `bg-black` / `rgba(255,255,255,1)` 铺满。85% 透明的纯白盖在浅底上，眼睛仍当它是白——透明度不算豁免。  
**反模式**：用 `#FAFAFA` 冒充已经避白（还是无色相的近白）；dark 用 `#0a0a0a` 装高级；把**例外**也禁掉——彩色填充上的字、视频烧录字幕、logo 反白、玻璃高光 1px，那些不是铺底。  
**开火路径**：`DESIGN.md` 色板、`:root` token、tour/popover 写死的实色。出海云 / 预算系统 2026-08 已按此改过一轮。

## 八、后端：不炫技的稳定

### 24. 幂等键（Idempotency-Key） `backend`

**是什么**：支付、下单、发码、扣额度——客户端带 UUID，服务端同键同响应。  
**为何杠杆**：网络重试不再变重复扣款；Stripe 式 header 是行业默契。  
**怎么落地**：存 `key → response` 24h；业务唯一约束作双保险。  
**反模式**：只幂等「创建订单」却不幂等「扣配额」；键用可猜测自增。  
**开火路径**：Checkout、webhook 处理、短信/邮件发送。

### 25. 队列：最便宜的架构升级 `backend`

**是什么**：发信、缩略图、webhook、AI 长任务移出 request-response。  
**为何杠杆**：接口 p99 与错误面立刻缩小；用 BullMQ / SQS / Postgres `SKIP LOCKED` 皆可。  
**怎么落地**：先拆「失败可重试且用户可稍后见结果」的副作用。  
**反模式**：所有逻辑进队列导致调试地狱；无死信与告警。  
**开火路径**：注册后发信、导出、第三方推送。

### 26. Feature Flag = 灰度 + 熔断 `backend` `ops`

**是什么**：DB 一张表或 Unleash 等；按用户/百分比开闭。  
**为何杠杆**：出 bug 不靠紧急重新部署；小团队的「后悔药」。  
**怎么落地**：新危险路径默认 off；准备一键全关。  
**反模式**：flag 永不删除变成永久分叉；用 flag 代替真正的设计决策。  
**开火路径**：支付改版、新权限模型、实验 UI。

### 27. 迁移纪律：先加后删、CONCURRENTLY `backend` `ops`

**是什么**：生产加索引用 `CREATE INDEX CONCURRENTLY`；列变更向后兼容（先加列双写，再切读，后删旧）。  
**为何杠杆**：零停机的核心是 DB 纪律，不是 K8s 玄学。  
**怎么落地**：迁移脚本进 CI；危险迁移写 rollback 笔记。  
**反模式**：直接删列、锁表加索引、大表同事务建索引。  
**开火路径**：每次 schema 变更。

### 28. 第三方调用：熔断 + 退避 `backend`

**是什么**：连续失败则短暂停呼；重试指数退避 + jitter。  
**为何杠杆**：一个支付/邮件/LLM 挂掉不应拖垮你全站线程与账单。  
**怎么落地**：超时明确；半开恢复；用户侧有降级文案。  
**反模式**：无限重试打爆对方与自己；吞掉错误当成功。  
**开火路径**：Stripe、邮件 API、模型推理、地图服务。

## 九、七天内能改决策的分析（反对虚荣仪表盘）

### 29. 只埋 5 个「能改下周优先级」的事件 `ops` `growth`

**是什么**：例如：`signed_up` → `activated`（你定义的 Aha）→ `key_action_weekly` → `checkout_started` → `paid`。  
**为何杠杆**：六个月后想问「谁用了 X」只能靠当初；但埋 200 个没人看的事件等于没埋。  
**怎么落地**：PostHog / 自建 events；每事件写清「若下降，我们下周改什么」。  
**反模式**：虚荣 DAU 大盘；无 activation 定义就优化文案。  
**开火路径**：产品第 1 周；每个新功能只加 1 个成功事件。

### 30. Session Replay 只看激活漏斗 `ops`

**是什么**：OpenReplay / 同类工具，抽查看用户卡在哪。  
**为何杠杆**：比问卷更接近真实挫败；用于修 onboarding，不是偷窥一切。  
**怎么落地**：采样；打码密码与 PII；只播「未激活」会话。  
**反模式**：全量录制无隐私政策；团队当娱乐看戏。  
**开火路径**：激活率停滞、某步高退出。

## 十、1–3 人运维节奏

### 31. `clone && make dev` 一条命令 `ops`

**是什么**：Docker Compose / 脚本把依赖、env 示例、迁移一次拉起。  
**为何杠杆**：未来的你（或兼职协作）30 分钟能开工；文档负债立刻下降。  
**怎么落地**：README 顶部三行：是什么 / 怎么跑 / 文档在哪。  
**反模式**：README 小说却跑不起来；秘钥写进仓库「示例」。  
**开火路径**：任何会活过下个月的项目。

### 32. 结构化日志 + Request ID `backend` `ops`

**是什么**：`logger.info({ event, userId, requestId })`；禁止无法检索的字符串散文。  
**为何杠杆**：小团队没有专职 SRE；一个 ID 贯穿日志/支持回复，是最便宜的可观测性。  
**怎么落地**：中间件生成 UUID，下传队列与外部回调。  
**反模式**：在日志里打 token/密码；只有 `console.log`。  
**开火路径**：所有 API 与 worker。

### 33. 安全基线：Headers + Rate limit + Secrets 不进 git `ops` `backend`

**是什么**：HSTS / CSP 基线 / `nosniff`；登录与 API 限流；Doppler/1Password/平台 Secrets。  
**为何杠杆**：10 分钟配置挡掉一整类低级事故；限流首先保护你免于自己的 bug 与账单爆炸。  
**怎么落地**：CF / 反代一层限流；`securityheaders.com` 扫到可接受；CI 扫密钥。  
**反模式**：CSP 严到产品不可用却不迭代；限流只防外人不管内部循环。  
**开火路径**：任何公网服务上线前。

### 34. 客户端校验 = UX；服务端再校验 = 安全 `backend`

**是什么**：价格、权限、优惠、数量——服务端必须重算。  
**为何杠杆**：十年老话，每周仍有人忘；支付边尤其致命。  
**怎么落地**：前端为了体验预检；后端权威；关键写路径单测覆盖篡改。  
**反模式**：信前端传来的 `price` / `role`。  
**开火路径**：Checkout、权限变更、优惠码。

## 十一、AI 产品：非显而易见的廉价赢

### 35. Token 流式输出 `frontend` `backend`

**是什么**：首字节尽快流式渲染，而不是等整段生成。  
**为何杠杆**：TTFT 体感决定「快还是死机」；与条目 3 的阶段文案可叠用。  
**怎么落地**：SSE / fetch stream；可停止生成；失败保留已生成部分。  
**反模式**：假打字机效果掩盖已完整返回的结果（用户识破后掉信任）。  
**开火路径**：聊天、长文生成、代码助手。

### 36. 引用工作过程与产物 `copy` `frontend`

**是什么**：展示用了哪些来源、中间提纲、将写入的文件/字段——让结果可审计。  
**为何杠杆**：AI 幻觉的信任解法不是「我们很准」，而是「你可以核对」。  
**怎么落地**：来源列表可点开；写操作前 diff 预览。  
**反模式**：虚假引用；引用不可点。  
**开火路径**：RAG 问答、自动改数据、代理执行。

## 十二、判断层：最大的杠杆是不做

### 37. 杀功能 / 杀细节的标准 `ops`

**是什么**：每季看使用数据；长尾功能、无人感知的动效、从未打开的设置——删。  
**为何杠杆**：代码与认知是负债；20% 功能常扛 80% 价值（经验法则，不是精密定律）。  
**怎么落地**：60 天无用 → 标记废弃 → 下线路径 + changelog 一句。  
**反模式**：因为「做都做了」而永久抚养。  
**开火路径**：路线图会、技术债日。

### 38. 两扇门（Bezos）：可逆就快跑 `ops`

**是什么**：单向门（定价模型、数据删除、品牌承诺）慢决策；双向门（文案、布局、实验 flag）快试。  
**为何杠杆**：小团队用「委员会流程」处理双向门，是效率灾难。  
**怎么落地**：PR 描述写一句「这是哪扇门」；单向门才拉多人。  
**反模式**：一切等齐人；或一切拍脑袋上生产不可逆。

### 39. Boring tech 与 YAGNI 预算 `ops` `backend`

**是什么**：创新预算花在业务差异；默认 Postgres / 熟悉框架；不为「未来可能」抽象。  
**为何杠杆**：Dan McKinley「Choose boring technology」——复杂度是税。  
**怎么落地**：新依赖要回答「没有它哪件事做不成」；抽象等到第二次重复。  
**反模式**：六个专用存储「微服务」服务 200 用户。

## 附 A · 工作示例：Premium One-pager 组合拳

> 这是**原则的示例包**，不是全手册的重心。适合营销长页 / 文档叙事页；B2B 后台不必照搬。

一次下午可装上的五件套，共同服务「我在哪 / 有反馈 / 有质感」：

1. **顶部 3px 滚动进度条**（渐变细线随滚动生长；可内嵌纸纹 soft-light）— 位置确定感  
2. **进视口 reveal 一次**（淡入 + 上浮 ~22–44px，不反复跳）— 节奏感  
3. **右侧章节点 / 固定舞台章节指示器**（衬线页码、当前章节名；浅底深墨或纸底衬）— 结构感  
4. **Paper Shaders 双层材质 veil**（真纸纹 + Perlin 噪点，multiply 极低透明；可动图层）— 材质感  
5. **细滚动条 + `::selection` + `scroll-behavior: smooth` + `prefers-reduced-motion` 降级** — 完成度

落地纪律：动画可关；动效不超过内容本身；不要把组合拳拆去每个 SaaS 表格页复读。

### texture 材质包（Paper Shaders 系） `frontend`

**是什么**：来自 [Paper Shaders](https://shaders.paper.design/) 的零依赖 shader 纹理（纸纹、Perlin/Simplex/Neuro 噪点等），导出 static webp/png 或 data URI；全页两层 `fixed` 覆盖（multiply + 极低透明度）。静图也可「活」——动的是图层 `transform`，不是文件本身。
**为何杠杆**：一杯咖啡成本兑现「有质感 / 手作感」，比自绘网格渐变便宜一个数量级；机制可迁移到任何低彩度纸/墨叙事页与 HTML deck，不绑某一品牌皮肤。
**怎么落地**：
1. Fetch `paper-texture` + `perlin-noise`（或等价噪点）；单文件交付时 base64 内联（纸纹 ~88KB raw 可接受）。
2. 两层 veil：`position:fixed; inset:0; pointer-events:none; z-index` 低于 UI、高于舞台底。子层 `inset:-3%` 给漂移留边；`background-size: 640px 480px`；`mix-blend-mode: multiply`。
3. **已验证透明度（lizliz deck 2026-08）**：纸纹 **0.085**、噪点 **0.05**。可用区间约纸纹 0.03–0.085、噪点 0.02–0.05；逼近上限必须截图验正文对比度。
4. **动效（四两拨千斤）**：纸纹 `tex-drift` — `90s linear infinite alternate`，`translate3d(-26px, 14px, 0)`；噪点 `tex-grain` — `3.4s ease-in-out infinite`，多关键位胶片抖动（约 ±7px）。两层 `will-change: transform`。配套微交互共用 `--ease-out-expo: cubic-bezier(0.16,1,0.3,1)`：列表行 hover `translateY(-2px)` + 轻影（0.24s）、面板 hover 可走横向 `translateX(4px)`、active 压下 0.08s、进场 reveal `translateY(22px)` 与翻页叠加。
5. 进度条（可选）：3px track + N 等分刻度；fill 内 `::before` 叠纸纹 `mix-blend-mode: soft-light`。
6. 固定舞台章节指示器（可选）：纸色底衬 + 深墨字（跨浅/深幻灯片都可读）；章节名 `word-break: normal; overflow-wrap: normal` + 最多两行 clamp——禁止单词/英文 token 正中断行。
7. 全部动画：`@media (prefers-reduced-motion: reduce) { … animation: none; transform 交互关闭 }`。
**反模式**：把 0.085 当装饰默认值往上加（过线立即糊字）；只写「>0.08 禁」却不截图验收；waves/大位移动效不做 PRM；把 `.flow-step` 与 `.panel` 写成同一套 hover 轴（实战里纵移/横移分工）；章节指示器浅字贴浅底、或 `word-break:break-all` 把章节名撕开；每个后台表格页都铺——组合拳只给叙事页 / deck。
**开火路径**：下午装——Paper Shaders fetch → 双层 veil CSS（对参：纸 0.085 / 噪 0.05 / drift 90s / grain 3.4s）→ 进度刻尺 → 右中章节指示器（纸底衬 + 深墨 + 禁中断行）→ 微交互 kit → PRM；验收：1280×720 截图正文不被糊、指示器在深浅页都可读。

## 用法（写进团队约定）

1. **别煮海**：一次只挑 3–5 条，进本周节奏。  
2. **先定义成功信号**：例如「支付重复投诉」「激活率」「支持工单里的『我点了没反应』」。  
3. **做完再测**：前后对比同一信号；没动信号就回滚或降级。  
4. **机制可迁移，清单条目不可宗教化**——Cmd+K、三档定价、one-pager 动效都有「不适合」的时候。

一句话：高杠杆细节的本质不是审美，是**廉价兑现承诺感**——在用户不确定的瞬间，让他觉得「这东西在替我兜底」。这就是四两拨千斤。
