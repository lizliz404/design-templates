# Hanzilla Personal Site Template

Warm editorial personal site pattern for an independent technical builder.

## Source

- Public sample: https://hanzilla.co/
- Extracted: 2026-05-28
- Scope: public design/template OSINT, not private source reuse

## Why it matters

This template is valuable because it combines:

- serif-led personal identity
- warm paper color system
- simple product/project proof cards
- blog posts as judgment proof
- one restrained product CTA

It avoids the usual personal-site mud: resume dump, AI-gradient nonsense, and overbuilt visual noise.

## Files

- `DESIGN.md` — distilled design system, component grammar, typography/color/layout rules
- `EVIDENCE.md` — public scan evidence, URL map, rendered style facts, screenshot notes
- `screenshots/` — visual evidence captured from the public site

## When to reuse

Use for:

- independent builder homepage
- technical founder profile
- devtool / AI tooling personal site
- writing + project hub
- product-led personal site

Avoid for:

- enterprise SaaS landing pages
- dense CV/resume sites
- image-heavy portfolios
- high-pressure conversion pages

## Core template skeleton

```txt
Header
Hero: identity + one-sentence positioning + two CTAs
Projects: shipped work cards
Writing: latest/selected posts cards
CTA: focused product/contact action
Footer
```

## Core visual recipe

```txt
warm off-white background
+ dark warm-brown text
+ Instrument Serif headings
+ Inter body/UI
+ rounded cards with subtle rings
+ generous whitespace
```
